# Iranildo — Site oficial

Site biográfico de Iranildo Santos da Silva. O projeto permanece local até aprovação expressa para publicação.

## Stack

- Vite e JavaScript puro: estrutura pequena e rápida.
- Anime.js: entrada e revelação das seções.
- WebP: imagens limitadas a 150 KB.

## Uso local

```bash
npm install
npm run dev
```

Para validar a versão final:

```bash
npm run build
npm run preview
```

## Estrutura

- `index.html`: conteúdo e metadados de compartilhamento.
- `src/main.js`: dados, galeria e interações.
- `src/style.css`: identidade visual e responsividade.
- `public/assets`: fotografias otimizadas.
